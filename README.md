# torch-crfsuite

A pure-PyTorch rewrite of [chokkan/crfsuite](https://github.com/chokkan/crfsuite) and [scrapinghub/python-crfsuite](https://github.com/scrapinghub/python-crfsuite) with ONNX export, `onnxruntime` inference, and a CLI tool (`crfsuite2onnx`) to convert existing CRFsuite `.model` files to ONNX.

## Features

- **Core `crf1d` Engine (`torch_crfsuite/crf1d.py`)**: `LinearChainCRF(nn.Module)` with sparse attribute scoring (`torch.sparse.mm`), log-space Forward-Backward, exact negative log-likelihood, marginal probabilities, and Viterbi decoding on CPU or CUDA.
- **Feature Extraction (`torch_crfsuite/features.py`)**: Full `ItemSequence` compatibility (flat dicts, booleans, string values, lists, nested dicts/lists/sets with `:` separator) plus `feature.minfreq`, `feature.possible_states`, and `feature.possible_transitions`.
- **All 5 CRFsuite Training Algorithms (`torch_crfsuite/trainers.py`)**:
  - `lbfgs` (`torch.optim.LBFGS` with Strong Wolfe line search and L1/L2 Elastic Net)
  - `l2sgd` (L2-regularized SGD with learning-rate calibration)
  - `ap` (Averaged Perceptron)
  - `pa` (Passive-Aggressive PA / PA-I / PA-II)
  - `arow` (Adaptive Regularization of Weight Vector)
- **`python-crfsuite`-Compatible API (`torch_crfsuite/api.py`)**: `Trainer`, `BaseTrainer`, `Tagger` (`open`, `open_inmemory`, `set`, `tag`, `probability`, `marginal`, `labels`, `info`, `dump`, `to_onnx`), and `ParsedDump`.
- **ONNX Export & ONNX Runtime (`torch_crfsuite/onnx_export.py`)**: `ONNXCRFModule`, `export_to_onnx`, and `OnnxTagger` for dependency-free production inference with `onnxruntime`.
- **CRFsuite-to-ONNX Converter (`torch_crfsuite/convert_crfsuite.py`)**: Convert existing binary `.model` files (e.g., `crf-wordseg.model` from [bact/nlp-thai](https://github.com/bact/nlp-thai/)) or `crfsuite dump` text files directly to ONNX.

## Converting Existing CRFsuite Models (e.g. `crf-wordseg.model`)

```bash
# Install with ONNX + CRFsuite reader support
pip install -e ".[onnx,crfsuite]"

# Convert a binary CRFsuite model directly to ONNX and verify with onnxruntime
crfsuite2onnx crf-wordseg.model crf-wordseg.onnx --verify

# Or convert a text dump generated by `crfsuite dump crf-wordseg.model > crf-wordseg.dump`
crfsuite2onnx crf-wordseg.dump crf-wordseg.onnx --verify
```

Then run inference with `OnnxTagger`:

```python
from torch_crfsuite import OnnxTagger

with OnnxTagger() as tagger:
    tagger.open("crf-wordseg.onnx")
    labels = tagger.tag([{"c[0]": "ส"}, {"c[0]": "ว"}])
```
